## 📖 Project Overview
This repository contains the network topology and configuration scripts for a Cisco Enterprise Networking, Security, and Automation (ENSA) practice assessment. The objective was to configure a simulated multi-site network (Ocisc LLC) implementing OSPFv2, NAT, ACLs, and device management.

The complete command logs and configurations are detailed in the attached document within this repository.

## 🛠️ Technologies & Skills Demonstrated
*   **Routing:** OSPFv2 (Multi-area, Router IDs, Interface-level activation, Auto-cost reference bandwidth, Hello/Dead timers).
*   **Security:** Standard and Extended Access Control Lists (ACLs) for VTY lines and traffic filtering.
*   **Translation:** Static NAT and Dynamic NAT with PAT (Port Address Translation).
*   **Network Management:** NTP synchronization and IOS image backup via TFTP.
